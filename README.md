## Sobre

Sou desenvolvedor full stack na **DMK3**, onde trabalho no **ITESP** — um sistema web para projeto do governo de São Paulo. Curso Engenharia de Software na FIAP, com formatura em 2029.

No dia a dia escrevo APIs em **NestJS** com **Prisma** e **PostgreSQL**, e interfaces em **React** com **TanStack Query**. Meu foco atual é arquitetura: separar bem as camadas e deixar o sistema fácil de mudar seis meses depois.

Fora do editor: treino PPL, e futebol no fim de semana. ⚽

## Projetos

### ITESP · DMK3 &nbsp;`produção`

Sistema web para um projeto do governo de São Paulo. Atuo nas duas pontas — telas em React com TanStack Query e a API em NestJS sobre PostgreSQL, com Prisma e TypeORM na camada de dados.

`React` `TanStack Query` `NestJS` `Prisma` `TypeORM` `PostgreSQL`

> Repositório privado — o código pertence à [DMK3](https://github.com/dmk3-dev).

### [Meteora](https://github.com/gfirmino231-spec/Loja-Fullstack)

E-commerce de moda construído como monorepo full stack, com **GraphQL como única camada de comunicação** entre front e back — sem REST no meio do caminho.

`NestJS` `GraphQL` `Apollo` `Prisma` `PostgreSQL` `React 19` `Vite`

[Repositório →](https://github.com/gfirmino231-spec/Loja-Fullstack)

### [OrbitWatch](https://github.com/gfirmino231-spec/OrbitWatch) &nbsp;`demo ao vivo`

Plataforma de monitoramento climático via satélite, feita para a Global Solution da FIAP. Tem uma camada edge em C++ que coleta os dados dos sensores e alimenta a aplicação web.

`React` `Vite` `CSS Modules` `React Router` `C++`

[Demo →](https://orbit-watch-wheat.vercel.app) &nbsp;·&nbsp; [Repositório →](https://github.com/gfirmino231-spec/OrbitWatch) &nbsp;·&nbsp; [Camada edge →](https://github.com/gfirmino231-spec/Orbitwatch-Edge-iot-)
